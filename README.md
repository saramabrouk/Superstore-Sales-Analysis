# Superstore Sales & Profitability Analysis — Power BI

## 📊 Project Overview

Interactive Power BI dashboard analyzing sales, profitability, customers, products, and regional performance using the Superstore dataset.

## 🎯 Objectives

- Analyze sales and profit performance
- Track key business KPIs
- Identify profitable categories and sub-categories
- Compare customer segments and regions
- Analyze sales trends over time
- Identify top-performing products

## 🛠️ Tools

- Excel — Data preparation
- Power BI — Data analysis & visualization
- DAX — KPI calculations

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Total Sales | $2.33M |
| Total Profit | $292.30K |
| Total Quantity | 39K |
| Total Orders | 5K |
| Profit Margin | 12.56% |

## 📈 Dashboard

The dashboard includes:

- Sales trends over time
- Profit by category
- Sales by customer segment
- Sales by region
- Sales vs. profit by category
- Profit by sub-category
- Top 5 products by sales
- Profit margin by category
